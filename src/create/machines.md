# 核心机械 | Create

Create 的加工机器围绕「给机器动力 → 投料 → 出成品」的循环展开。本文按加工类型介绍最常用的机器。

> [!NOTE]
> 所有机器都需要动力驱动（见[动力与应力](./rotation.md)）。配方查询推荐游戏内 EMI（theArcadia 已内置），可按机器类型筛选配方。

---

## 加工机器一览

### 动力搅拌器（Mechanical Mixer）+ 工作盆（Basin）

最常用的组合。搅拌器悬在工作盆上方旋转即可**无配方栏混合**物品：投入原料（或右键工作盆放入），满足配方就自动产出。

- 需要加热的配方（如安山岩合金、黄铜）在工作盆下方放置火/岩浆块/烈焰人燃烧室
- **烈焰人燃烧室（Blaze Burner）**喂烈焰蛋糕后进入超级加热，可解锁更高档配方

### 粉碎轮（Crushing Wheels）

一对面对面放置的大型滚轮，把方块碾碎成更细的产物：

- 矿石粉碎可获得**双倍以上产出**（如铁矿石 → 粉碎 → 2 铁锭 + 概率经验碎片）
- 支持粉碎圆石成沙、下界岩等转化
- 每台消耗 8 SU 应力，是前期最「吃」动力的机器，注意[应力余量](./rotation.md#应力stress)

### 动力冲压机（Mechanical Press）

垂直冲压下方的物品：

- 冲压金属锭 → 对应**薄板（Sheet）**；冲压面粉 → 面团等
- 配合**置物台（Depot）**逐件加工，或配合**皮带**实现流水线连续冲压
- 冲压路径上放置漏斗状方块可改变产物（如冲压成轨道）

### 动力锯（Mechanical Saw）

- 竖直放置：切割下方物品（原木 → 无限剥皮原木循环、木板加工）
- 水平放置：切割经过的整排方块，伐木场核心

### 动力钻头（Mechanical Drill）

持续钻挖前方的方块，常用于采矿隧道挖掘机或配合矿机刷石机。

### 机械手（Mechanical Arm）

**物品搬运多面手**：从取物点抓取物品放到投放点，最多记忆 20 个「取—放」路线，是自动化产线的骨架。

- 取物点：箱子、置物台、皮带等任何容器
- 投放点：工作盆、机器输入口、熔炉等
- 用**列表过滤器（Filter）**可精细控制它只搬哪几样

### 鼓风机（Encased Fan）

多功能气流机器：

- **吹风**：推动物品沿皮带移动、给玩家/生物推力
- **加热**（下方放热源）：吹过皮带上方的物品进行**烟熏/熔炼**（生牛肉 → 牛排）
- **水流**（下方放水）：洗涤产物（砂砾 → 铁粒）

## 经典自动化组合

| 目标 | 推荐组合 |
|:-----|:---------|
| 矿石翻倍 | 粉碎轮 + 溜槽收集 + 熔炉/鼓风机熔炼 |
| 面包流水线 | 石磨磨小麦 → 动力冲压机压面团 → 鼓风机烘烤 |
| 无限刷铁 | 机械手投料 + 熔炉阵列 + 溜槽回收（配合刷铁机等设计） |
| 大规模仓储 | 动力臂 + 物品保险库（Item Vault）+ 打包机物流 |

> 📖 每台机器的游戏内演示请用 **Ponder 图鉴**（默认按键 `G`）。
