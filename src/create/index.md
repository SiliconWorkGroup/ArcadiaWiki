## 简介

**Create** 是一个专注于机械自动化与装饰建造的模组。它用一套直观的**旋转动力（Rotation）**系统取代传统的"发电—管道传输"模式：水车、蒸汽机产生旋转力，齿轮、皮带把动力传递到搅拌器、机械手等各类机器上，所有装置都由你亲手搭建、亲眼看着运转。

> [!NOTE]
> theArcadia 内置 **Create 6.0.10+mc1.21.1**，并额外内嵌了 30 余个 Create 系附属模组——从大炮到空艇、从附魔自动化到家具装饰一应俱全，详见[整合包附属指南](./addons.md)。

Create 的核心乐趣可以概括为三件事：

1. **⚙️ 机械动力**：搭建旋转动力网络，驱动各种加工机器
2. **🚂 列车物流**：铺设轨道、组装列车，建立跨区域货运网络
3. **🏗️ 装置建造**：利用活塞、轴承组装可移动的机械装置与装饰建筑

## 与整合包内模组的联动

theArcadia 中多个模组会与 Create 自动联动：

| 模组 | 联动内容 |
|:-----|:---------|
| **Spelunkery** | 新增深板岩锌矿石掉落的粗锌矿粒；禁用自带铜矿粒改用 Create 的；为新增方块提供灌注、排空、混合、粉碎配方，详见 [Spelunkery 词条](../spelunkery/index.md) |
| **Sophisticated Backpacks / Storage** | 通过内嵌的集成模组，背包与容器可随 Create 装置一同移动运作 |
| **AE2 (应用能源)** | 通过 Applied Create 等桥接附属连接电力与旋转动力体系 |
