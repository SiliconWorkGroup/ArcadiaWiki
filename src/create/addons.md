# 整合包附属指南 | Create

theArcadia 除 Create 本体外，还内嵌了 **30 余个 Create 系附属模组**。本文按用途分类介绍，帮你快速找到「这个功能是哪个模组提供的」。

> [!NOTE]
> 以下清单经 Modrinth API 对 theArcadia nextStage A6.96 的 225 个依赖逐一核实，均为**实际装载**的模组，可放心对照游戏内容。

---

## ⚙️ 动力与发电

| 模组 | 内容 |
|:-----|:-----|
| **Create Crafts & Additions** | 在旋转动力与**电力（FE）**之间架起桥梁：电动马达、电力发电机、电缆 |
| **Create: Diesel Generators** | 紧凑型柴油机与原油精炼：钻井采油 → 炼油 → 柴油发电 |
| **Create: Power Grid** | 为 Create 世界引入电网系统 |
| **Applied Create / Applied Kinetics** | 连接 AE2 应用能源与 Create 动力体系 |

## 🚂 列车与移动装置

| 模组 | 内容 |
|:-----|:-----|
| **Create Aeronautics** | 造**会飞的载具**：从空艇到飞机，整栋建筑起飞 |
| **Waystones: Sable** | 让 Waystones 在 Aeronautics 移动结构上正常传送 |
| **Create: Blocks & Bogies** | 更多大型转向架（含装饰性阀动装置），强化列车外观 |
| **Create: Misc and Things / Dragons Plus** | 杂项实用方块与开发者工具 |

## 🌾 农业与食物自动化

| 模组 | 内容 |
|:-----|:-----|
| **Create Slice & Dice** | 让 Create 机械自动化**农夫乐事**（Farmer's Delight）的切菜、烹饪流程（整合包已内置农夫乐事） |
| **Create: Integrated Farming** | 集成化农场自动化 |
| **Create: Gears and Tavern** | 自动化**万象酒馆**（Kaleidoscope Tavern，整合包已内置）的运营 |

## ✨ 附魔与装备

| 模组 | 内容 |
|:-----|:-----|
| **Create: Enchantment Industry** | 附魔自动化：经验收集、附魔机、附魔分离与注入 |
| **Create Stuff 'N Additions** | 磁力装备、新工具与新武器套装 |

## 🔫 武器娱乐

| 模组 | 内容 |
|:-----|:-----|
| **Create Big Cannons** | 用 Create 方块建造**大口径火炮**：铸炮膛、装填发射药、实弹射击 |

## 🏗️ 装饰建造

| 模组 | 内容 |
|:-----|:-----|
| **Create Deco** | 工业风装饰方块：栏杆、铁皮墙、警示条等 |
| **Create: Design n' Decor** | 更多建材：染色机壳、瓷砖、家具件 |
| **Create: Prismatic Shine** | 玻璃机壳与发光机壳，机械内部一目了然 |
| **Create Interiors** | 家具套件：沙发、桌子、灯具等室内陈设 |
| **Copycats+** | 「伪装方块」全家桶：让齿轮箱、管道等披上任意方块外观 |

## 📦 物流增强

| 模组 | 内容 |
|:-----|:-----|
| **Sophisticated Storage / Backpacks Create Integration** | 高级存储与背包随 Create 移动装置工作 |
| **Create: FluidLogistic** | 流体运输接入纸壳包裹物流网络 |
| **Deployer (API)** | 扩展物流、仪表与流体系统的库模组 |
| **Create: Connected** | 一批高度可配置的 QoL 方块 |
| **Create: Extra Gauges** | 新型仪表，处理复杂逻辑监控 |
| **Create: Dreams & Desires** | 契合 Create 主题的杂项内容 |

## 🛠️ 体验优化

| 模组 | 内容 |
|:-----|:-----|
| **Create: Dynamic Lights** | 移动装置上的光源实时照亮环境 |
| **Create: Tweaked Controllers** | 用高级控制器操控你的机械装置 |
| **Create: Escalated** | 功能性**自动扶梯**——旋转动力驱动的升降观光梯 |
| **Create: CC Better Recipes** | 平衡调整：CC:Tweaked（电脑）配方改用 Create 材料 |

---

> [!TIP]
> 记不住这么多？游戏内遇到任何不认识的方块，先看它的材质风格（安山岩=基础/黄铜=进阶/铜=流体），再按 `G` 打开 Ponder 图鉴查用法；仍找不到就回到本页按分类定位模组。
