# 物流与流体 | Create

Create 的物流分三层：**方块运输**（溜槽/漏斗）、**流体管道**、以及 6.x 新增的**纸壳包裹物流**。从简单分拣到跨基地补给都能覆盖。

---

## 物品运输

### 溜槽（Chute）与智能溜槽（Smart Chute）

- **溜槽**：垂直方向掉落运输，成本极低
- **智能溜槽**：可设置过滤与抽取数量，红石可控

### 漏斗（Funnel）

安装在皮带/容器边缘的「接口」：

- **安山漏斗（Andesite Funnel）**：从皮带取放物品的基础件
- **黄铜漏斗（Brass Funnel）**：支持过滤器与红石控制，精准抽取指定物品

> [!TIP]
> 漏斗有「取物/放物」两种模式，用扳手右键切换。装反是新手最常见的问题。

### 动力臂与置物台

大批量分拣交给[机械手](./machines.md#机械手mechanical-arm)；单格暂存用**置物台（Depot）**——它就是一台「裸露的皮带」，常用于冲压、打磨的工位。

## 流体系统

| 组件 | 用途 |
|:-----|:-----|
| **流体储罐（Fluid Tank）** | 存储流体，可堆叠成大型储罐 |
| **流体管道（Fluid Pipe）** | 输送流体；用扳手开窗口连接 |
| **动力泵（Mechanical Pump）** | 给管网加压，驱动流体流动 |
| **智能流体管道（Smart Fluid Pipe）** | 带过滤器，只放行指定流体 |
| **注液器（Spout）** | 向下方物品灌注流体（给玻璃瓶灌水/岩浆瓶、给空桶充装等） |
| **分液池（Item Drain）** | 沥干物品携带的流体（湿海绵 → 海绵） |
| **软管滑轮（Hose Pulley）** | 从湖/无限水中抽水或排空液体 |
| **铜背罐（Copper Backtank）** | 可穿戴气罐，为喷气背包等供压 |

> [!WARNING]
> 管道不加压不会流动。一段管网上放一台动力泵并接入动力即可；长距离多泵分段加压。

## 纸壳包裹物流（6.x 新版特色）

Create 6 重做了工厂级物流：把物品打成**纸壳包裹（Package）**，通过传送网络集中调度。

| 组件 | 角色 |
|:-----|:-----|
| **打包机（Packager）** | 把相邻容器内的物品自动打包成纸壳包裹 |
| **货物蛙港（Package Frogport）** | 包裹的收发端口，装在溜槽/容器上接收分发包裹 |
| **邮箱（Postbox）** | 手动寄出指定包裹到目标地址 |
| **理包机（Repackager）** | 把到达的包裹重新分拣打包 |
| **仓储发报机（Stock Ticker）** | 远程下单：对着网络申请任意物品并自动发货 |
| **红石请求器（Redstone Requester）** | 红石触发的一次性补货请求 |

**典型用法**：产线末端放一台打包机 → 蛙港把包裹发往中央仓库 → 仓库用理包机拆包归档 → 玩家用仓储发报机远程点货，物资自动送到面前。

## 与整合包模组的联动

- **Sophisticated Backpacks / Storage**：内嵌集成模组让背包与高级存储容器能随 Create 移动装置工作
- **Create: FluidLogistic**（已内嵌）：把流体运输也纳入纸壳包裹式物流网络
- **AE2**：Applied Create 桥接旋转动力与 ME 能量体系
