# 入门指南 | Create

本文带你走完 Create 的起步流程：从安山岩合金到第一台运转的机器。

> [!NOTE]
> 本文基于 theArcadia 内置的 Create 6.0.10（MC 1.21.1）。游戏内按 `G` 键可随时打开 **Ponder 图鉴**，逐格动画演示每个方块的用法——比任何文字教程都直观，遇到不懂的机器先查它。

---

## 第一步：安山岩合金

**安山岩合金（Andesite Alloy）** 是 Create 的基础材料，几乎所有初级机器都离不开它。

| 获取方式 | 配方 |
|:---------|:-----|
| 工作台合成 | 2 安山岩 + 2 铁粒（或 2 锌粒）→ 1 安山岩合金 |
| 动力搅拌器 | 1 安山岩 + 1 铁粒（或 1 锌粒）+ 加热 → 2 安山岩合金 |

前期挖安山岩和铁矿即可大量生产。进阶材料**黄铜（Brass）**需要用动力搅拌器混合铜锭与锌锭获得。

---

## 第二步：第一台水车

水车是最容易上手的动力来源：

1. 挖一条 3 格深的沟，两端倒水形成**环绕水流**
2. 将**水车（Water Wheel）**放入水流中间——它会自动开始旋转
3. 用**轴（Shaft）**从水车侧面接出动力，连接到机器上

> [!TIP]
> 水流方向要与水车旋转方向一致，逆流水车只有一半转速。手持**工程师护目镜（Engineer's Goggles）**右键任何动力方块，可以看到实时转速与应力数据。

## 常用工具

| 工具 | 用途 |
|:-----|:-----|
| **扳手（Wrench）** | 调整/拆卸机器朝向，旋转方块，右键轴类可切换传力方向 |
| **工程师护目镜** | 查看转速（RPM）与应力（SU）数值 |
| **砂纸（Sand Paper）** | 打磨粗糙宝石等物品；放在置物台上右键可自动打磨 |
| **蓝图（Schematic）** | 配合蓝图桌与蓝图加农炮，复制粘贴整栋建筑 |

> [!WARNING]
> 用扳手**潜行+右键**可以完整拆下机器（保留内部物品），普通左键破坏则可能损毁机器本体。
